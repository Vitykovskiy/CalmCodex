# История версий

## В разработке

- Добавлен отдельный режим подготовки промпта: цель, контекст, ограничения и ожидаемый результат из черновика. Правила и официальные источники зафиксированы в `docs/prompt-mode.md`.
- В контекстном меню VS Code и службах macOS доступна команда **Подготовить промпт для Codex**. Настройка `calmCodex.mode` выбирает режим автоматической обработки; по умолчанию остаётся редактура.
- CLI принимает `--stdin --mode prompt`; прежний вызов `--stdin` сохраняет поведение редактора.
- Восстановление буквальных фрагментов отклоняет перестановку меток и склеивание отдельных блоков с окружающим текстом.

## 2.1.0 · 27 ноября 2026

- Luna распознаёт явные риторические упрёки и сарказм в черновике. Реплика «Для кого, блядь, написаны инструкции?» в роли упрёка превращается в «Соблюдай инструкции». Настоящие вопросы сохраняются.
- При самоисправлении с именем файла, командой или другим защищённым фрагментом редактор сохраняет слова отмены и исходный порядок фрагментов.

## 2.0.1 · 27 ноября 2026

- Обновлён промпт Luna для VS Code и службы macOS. Наблюдение остаётся наблюдением, вопрос — вопросом.
- При самоисправлении редактор сохраняет последнее намерение и явные запреты. При правке диктовки сохраняет оговорки вроде «кажется», имена и технические детали.

## 2.0.0 · 27 ноября 2026

- Enter и кнопка отправки в VS Code передают Codex переформулированный текст.
- Контекстное меню позволяет проверить результат в черновике и обработать отдельное выделение.
- Тот же обработчик принимает готовую расшифровку диктовки. Служба macOS доступна в других приложениях.
