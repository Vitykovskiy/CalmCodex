# История версий

## Следующая версия

- Режим подготовки промпта собирает соседние обычные абзацы в цельную задачу. Вложения, код и форматирование ограничивают перестройку; частичное выделение сохраняет адресную замену.
- При подготовке промпта каждый фрагмент получает соседний текст сообщения как контекст для понимания. Замена остаётся привязанной к исходному фрагменту; вложения и форматирование сохраняются прежним механизмом.
- Уточнены правила для риторических вопросов о необходимости самому догадываться или представлять результат. Добавлены контрастные примеры настоящих вопросов и отдельный набор проверок с моделью.
- Ultracave дополнительно сжимает текст в обоих режимах и включён по умолчанию. Переключатель `calmCodex.ultracave`, настройка службы `ultracave` и CLI-флаги `--ultracave` / `--no-ultracave` управляют сжатием. Отдельного обращения к модели нет.
- Модель и уровень рассуждений переписчика доступны в настройках VS Code и параметрах CLI. Модель по умолчанию остаётся `gpt-6-luna`, уровень рассуждений изменён с `low` на `medium`.
- CLI принимает `--stdin-json` с редактируемым `draft` и необязательным контекстом `before`/`after`; прежний текстовый ввод сохранён.

## 2.2.0 · 27 ноября 2026

- Добавлен отдельный режим подготовки промпта: цель, контекст, ограничения и ожидаемый результат из черновика. Правила и официальные источники зафиксированы в `docs/prompt-mode.md`.
- В контекстном меню VS Code и службах macOS доступна команда **Подготовить промпт для Codex**. Настройка `calmCodex.mode` выбирает режим автоматической обработки; по умолчанию остаётся редактура.
- CLI принимает `--stdin --mode prompt`; прежний вызов `--stdin` сохраняет поведение редактора.
- Восстановление буквальных фрагментов отклоняет перестановку меток и склеивание отдельных блоков с окружающим текстом.
- Отступы и хвостовые пробелы отдельных строк с буквальными фрагментами восстанавливаются из исходного черновика вместо отказа из-за нормализации пробелов моделью.
- Режим подготовки промпта изолирует участки вокруг вложений, блоков кода и абзацев. Форматирование внутри фразы сохраняется вместе с её контекстом. Абзац из одного междометия можно убрать без отмены остальной задачи.
- Уточнено различие между вопросом об аудитории документа и поручением изменить его обложку; добавлена повторяемая проверка на текущей сборке с Luna.

## 2.1.0 · 27 ноября 2026

- Luna распознаёт явные риторические упрёки и сарказм в черновике. Реплика «Для кого, блядь, написаны инструкции?» в роли упрёка превращается в «Соблюдай инструкции». Настоящие вопросы сохраняются.
- При самоисправлении с именем файла, командой или другим защищённым фрагментом редактор сохраняет слова отмены и исходный порядок фрагментов.

## 2.0.1 · 27 ноября 2026

- Обновлён промпт Luna для VS Code и службы macOS. Наблюдение остаётся наблюдением, вопрос — вопросом.
- При самоисправлении редактор сохраняет последнее намерение и явные запреты. При правке диктовки сохраняет оговорки вроде «кажется», имена и технические детали.

## 2.0.0 · 27 ноября 2026

- Enter и кнопка отправки в VS Code передают Codex переформулированный текст.
- Контекстное меню позволяет проверить результат в черновике и обработать отдельное выделение.
- Тот же обработчик принимает готовую расшифровку диктовки. Служба macOS доступна в других приложениях.
