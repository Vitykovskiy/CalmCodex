# История версий

## 2.0.1 · 27 ноября 2026

- Обновлён промпт Luna для VS Code и службы macOS. Наблюдение остаётся наблюдением, вопрос — вопросом.
- При самоисправлении редактор сохраняет последнее намерение и явные запреты. При правке диктовки сохраняет оговорки вроде «кажется», имена и технические детали.

## 2.0.0 · 27 ноября 2026

- Enter и кнопка отправки в VS Code передают Codex переформулированный текст.
- Контекстное меню позволяет проверить результат в черновике и обработать отдельное выделение.
- Тот же обработчик принимает готовую расшифровку диктовки. Служба macOS доступна в других приложениях.
