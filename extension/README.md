# CalmCodex для VS Code

Наберите или надиктуйте сообщение в чате Codex и отправьте его обычным способом. Перед отправкой независимая сессия Codex с моделью `gpt-6-luna` переформулирует текст. При ошибке модели отправка отменяется.

Чтобы посмотреть формулировку, щёлкните правой кнопкой прямо в поле ввода и выберите **Переформулировать для Codex**. Без выделения обрабатывается весь черновик. Если выделена часть текста, заменится только эта часть. Замена поддерживает обычную отмену редактирования. При изменении черновика во время обработки CalmCodex отменяет устаревший результат. Пустые сообщения, вложения и команды Codex обрабатываются штатно.

В настройках VS Code параметр `calmCodex.rewriteOnSend` управляет автоматической обработкой. Команда контекстного меню доступна и при выключенной автоматической обработке.

Расширение работает локально на macOS и использует текущий вход в Codex. Модели передаётся текст черновика. Обработку кода, ссылок и буквальных фрагментов выполняет встроенный движок CalmCodex. Выбор модели и пути к Codex CLI использует настройки `local.calmcodex.service`.

Публичный API VS Code позволяет расширить контекстное меню, но доступ к черновику и нативной отправке предоставляет сам редактор Codex. При установке CalmCodex добавляет небольшой адаптер в локальную копию `openai.chatgpt`. При обновлении Codex расширение проверяет совместимость заново. Если формат редактора изменился, CalmCodex покажет сообщение об ошибке. Для полного удаления адаптера и расширения используйте **Remove-VSCode.command** из архива и перезагрузите окно.
