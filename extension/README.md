# CalmCodex для VS Code

**Из живой речи — в ясную задачу для Codex.**

Надиктовывайте задачу с уточнениями, повторами и эмоциями. CalmCodex помогает собрать из черновика понятный запрос, сохранив цель, вопросы и ограничения — прямо в поле ввода Codex.

Например, реплика «Я просил только выровнять кнопку. Кто тебя просил переписывать весь экран?» может стать «Ограничь изменения выравниванием кнопки». Это пример преобразования упрёка в границы задачи; конкретная формулировка зависит от модели.

Отправляйте сообщение обычным способом или сначала просмотрите результат через контекстное меню. При сбое модели исходный черновик сохраняется. [Больше примеров и исходный код](https://github.com/Vitykovskiy/CalmCodex).

Чтобы посмотреть формулировку, щёлкните правой кнопкой прямо в поле ввода и выберите **Переформулировать для Codex**. Без выделения обрабатывается весь черновик. Если выделена часть текста, заменится только эта часть. Замена поддерживает обычную отмену редактирования. При изменении черновика во время обработки CalmCodex отменяет устаревший результат. Пустые сообщения, вложения и команды Codex обрабатываются штатно.

Для составления задачи выберите **Подготовить промпт для Codex**. Этот режим выделяет цель, контекст, ограничения и описанный результат, сохраняя вопросы, условия и буквальные фрагменты. Он использует только сведения из черновика; простому запросу достаточно короткой формулировки.

Абзацы и участки вокруг вложений или блоков кода обрабатываются отдельно. Фраза с разным форматированием передаётся целиком, чтобы сохранить смысл. Такой черновик может обрабатываться дольше. При сбое модели исходный черновик сохраняется целиком.

В настройках VS Code параметр `calmCodex.rewriteOnSend` управляет автоматической обработкой, а `calmCodex.mode` выбирает `rewrite` (редактура, по умолчанию) или `prompt` (подготовка задачи). Обе команды контекстного меню доступны и при выключенной автоматической обработке. Каждая ручная команда выбирает собственный режим. После обработки целого черновика через меню отправка не вызывает модель повторно, пока черновик не изменён.

Расширение работает локально на macOS и использует текущий вход в Codex. Модели передаётся текст черновика. Обработку кода, ссылок и буквальных фрагментов выполняет встроенный движок CalmCodex. Выбор модели и пути к Codex CLI использует настройки `local.calmcodex.service`.

Публичный API VS Code позволяет расширить контекстное меню, но доступ к черновику и нативной отправке предоставляет сам редактор Codex. При установке CalmCodex добавляет небольшой адаптер в локальную копию `openai.chatgpt`. При обновлении Codex расширение проверяет совместимость заново. Если формат редактора изменился, CalmCodex покажет сообщение об ошибке. Для полного удаления адаптера и расширения используйте **Remove-VSCode.command** из архива и перезагрузите окно.
