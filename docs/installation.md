# CalmCodex

Наберите или надиктуйте сообщение в чате Codex и отправьте его обычным способом. Перед отправкой независимая сессия Codex с моделью `gpt-6-luna` переформулирует текст. При ошибке модели отправка отменяется.

Чтобы посмотреть формулировку, щёлкните правой кнопкой прямо в поле ввода и выберите **Переформулировать для Codex**. Без выделения обрабатывается весь черновик. Если выделена часть текста, заменится только эта часть. Замена поддерживает обычную отмену редактирования. При изменении черновика во время обработки CalmCodex отменяет устаревший результат. Пустые сообщения, вложения и команды Codex обрабатываются штатно.

Для составления задачи выберите **Подготовить промпт для Codex**. Этот режим собирает цель, контекст, ограничения и описанный результат в краткую постановку задачи; использует только сведения из черновика.

В настройках VS Code параметр `calmCodex.rewriteOnSend` управляет автоматической обработкой. Параметр `calmCodex.mode` выбирает `rewrite` (редактура, по умолчанию) или `prompt` (подготовка задачи). Обе команды контекстного меню доступны и при выключенной автоматической обработке и выбирают собственный режим. Готовый целый черновик после ручной обработки отправляется без повторного обращения к модели, пока текст не изменён.

`calmCodex.ultracave` дополнительно сжимает текст в обоих режимах. По умолчанию включён; отключите переключатель для обычной обработки. Сжатие сохраняет вопросы, предположения и ограничения и выполняется в том же запросе к модели. Для службы macOS его можно отключить командой `defaults write local.calmcodex.service ultracave -bool false`; для отдельного вызова CLI доступны `--ultracave` и `--no-ultracave`. Настройка VS Code имеет приоритет перед настройкой службы.

Для установки распакуйте архив и откройте **Install.command**. Если окно VS Code было открыто во время установки, один раз выполните **Developer: Reload Window** через **⌘⇧P**.

Расширение работает на macOS и использует текущий вход в Codex. Модели передаётся текст черновика; при обработке по частям соседний текст доступен как контекст для понимания. Обработку кода, ссылок и буквальных фрагментов выполняет встроенный движок CalmCodex. Настройки модели описаны ниже; путь к Codex CLI задаётся через `local.calmcodex.service`.

Публичный API VS Code позволяет расширить контекстное меню, но доступ к черновику и нативной отправке предоставляет сам редактор Codex. При установке CalmCodex добавляет небольшой адаптер в локальную копию `openai.chatgpt`. При обновлении Codex расширение проверяет совместимость заново. Если формат редактора изменился, CalmCodex покажет сообщение об ошибке. Для полного удаления адаптера и расширения используйте **Remove-VSCode.command** из архива и перезагрузите окно.

## Служба для других приложений macOS

Выделите текст в редактируемом поле и вызовите **Переформулировать для Codex** или **Подготовить промпт для Codex** из меню служб приложения. В самом VS Code используйте Enter или правый клик прямо в чате. Для установки только интеграции VS Code запустите **Install-VSCode.command**.

Для чтения из стандартного ввода движок принимает `CalmCodex --stdin` (редактура) и `CalmCodex --stdin --mode prompt` (подготовка задачи).

## Выбор модели и CLI

В VS Code задайте `calmCodex.model` и `calmCodex.reasoningEffort`. Эти параметры управляют переписчиком; выбор модели в основном чате Codex на них не влияет. Например, для сравнения с Luna выберите `gpt-6.2-sol` и `medium`.

Пустые значения наследуют настройки службы macOS. По умолчанию используются `gpt-6-luna` и `medium`; доступны уровни `low`, `medium`, `high`, `xhigh`, `max`. Повышение уровня может увеличить задержку и расход лимита. Для службы macOS настройки задаются в Терминале:

~~~sh
defaults write local.calmcodex.service model -string 'gpt-6.2-sol'
defaults write local.calmcodex.service reasoningEffort -string 'medium'
~~~

Команды `defaults delete local.calmcodex.service model` и `defaults delete local.calmcodex.service reasoningEffort` возвращают значения по умолчанию, если они были сохранены. При необходимости перезапустите службу macOS, чтобы она прочитала новые настройки.

CLI принимает переопределения `--model gpt-6.2-sol --reasoning-effort medium` вместе с `--stdin` или `--stdin-json`. Приоритет: параметры вызова → настройки службы → значения по умолчанию. Выбранная модель должна быть доступна текущему аккаунту Codex. Формат JSON для передачи контекста описан в [руководстве режима](prompt-mode.md#модель-и-уровень-рассуждений).

Для собственного расположения CLI укажите полный путь к исполняемому файлу.

~~~sh
defaults write local.calmcodex.service cliPath -string '/полный/путь/к/codex'
~~~

Чтобы удалить службу, переместите **~/Library/Services/CalmCodex.service** в Корзину. Исходный код, правила редактирования и скрипт сборки находятся в папке **Source**. Сборка требует Xcode Command Line Tools.
